Detailed Description

Invoker in the Command pattern: holds one command for each workflow action and runs the right one when asked.

The controller creates its five commands once, for a single WorkItem, and deletes them when it is destroyed. The SystemProcessor (facade) only ever talks to the controller, never to the commands directly.
