Detailed Description

Keeps one prototype per output name and hands out copies of it.

The registry owns every prototype registered with it and deletes them when it is destroyed or when they are replaced or removed. Objects returned by createOutput() are copies owned by the caller, so changing one never changes the stored prototype or any other copy.

We deceded that a registry cannot be copied or assigned: a copy would share the same prototypes, and both registries would delete them.
