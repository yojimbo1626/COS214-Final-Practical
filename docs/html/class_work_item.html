◆ WorkItem() [2/2]

WorkItem::WorkItem ( const WorkItem & workItem)

Copy constructor.

Copies the name and description. The copy always starts in the Available state, because the states have no clone() method to copy the original's current state. The copy starts with no observers: Participants subscribed to the original are not subscribed to the copy.

Parameters
workItemThe WorkItem to copy.

◆ setState()

void WorkItem::setState ( WorkItemState * newState)

Replaces the current state and deletes the old one.

Called by the concrete states when a transition happens. Does nothing if newState is null or already the current state. After the change, every observer is notified of the new state.

Parameters
newStateThe new state. The WorkItem takes ownership of it.
Warning
The old state is deleted. When a concrete state calls this on itself, it must return immediately afterwards.
