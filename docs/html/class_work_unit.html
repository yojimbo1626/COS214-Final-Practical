Detailed Description

Abstract WorkUnit in the Observer pattern.

Keeps the list of observers and pushes updates to them.

Pure virtual destructor: makes WorkUnit abstract.

It still needs a body, because every derived class destructor calls it. The observers are not deleted: the WorkUnit does not own them.

◆ notify()

void WorkUnit::notify ( std::string update)

Pushes an update message to every subscribed Participant.

Push model: the concrete WorkUnit builds the message and passes it in, so observers get everything they need without querying the WorkUnit.

Loops over a copy of the observer list, so an observer can safely unsubscribe itself from inside receiveUpdate().

Parameters
updateThe message to send to every observer.
