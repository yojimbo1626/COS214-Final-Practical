WorkItemState * Completed::clone ( )
virtual

Creates an independent copy of this state.

Used by WorkItem::createSnapshot() (Memento). A snapshot must own its own state object, because the WorkItem deletes its current state on every transition: storing the WorkItem's own pointer would leave the snapshot pointing at deleted memory.

A new Completed object. The caller takes ownership of it.
